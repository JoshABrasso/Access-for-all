Proof points

Each section exercises a different part of the contract.

The cards, buttons, and supporting copy below should all respond to the engine without one-off overrides.

Reading

Focused reading and spacing

Reading mode narrows measure on real content surfaces. Line, paragraph, letter, and word spacing all inherit from runtime tokens.

Why this matters

The demo is smaller on purpose.

Interaction

A small tabbed widget to exercise shared runtime UI

This uses the optional data-platform-explorer behavior from site-ui.js so the proof page still checks one richer interaction.

The goal of this page is not breadth for its own sake. It is to show that the real template primitives respond coherently when the engine state changes.

  • The engine writes root data-* attributes and runtime CSS variables.
  • Shared CSS consumes those tokens across shell, cards, forms, and modal UI.
  • The page avoids large local style systems that would weaken the proof.

For handoff, keep index.html as the real starter, keep engine.html as technical reference if useful, and delete this page before launch.

Finish line
